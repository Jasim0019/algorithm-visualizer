# ⚡ Algorithm & Logic Visualizer

An interactive, responsive algorithm visualization suite created to simulate and study core sorting and searching algorithms with real-time telemetry and audio synthesis.

Developed by **[Shaik Mohammed Jasim](https://github.com/Jasim0019)** (B.Tech Computer Science and Engineering with Specialization in AI & ML, SRM University, 2025–2029).

---

## 🌟 Key Features

- **Supported Algorithms**:
  - **Quick Sort**: Divide and conquer with random partitioning.
  - **Merge Sort**: Stable logarithmic time complexity.
  - **Bubble Sort**: Classic pairwise adjacent comparison.
  - **Insertion Sort**: Online incremental sorted subarray builder.
  - **Binary Search**: Logarithmic search over sorted datasets.
- **Real-Time Telemetry**:
  - Live comparison counter.
  - Live array access and swap tracker.
  - Big-O time and auxiliary space complexity badges.
- **Audio Feedback**:
  - Web Audio API tone generation mapped to array values during comparisons.
- **Interactive Controls**:
  - Dynamic array size slider (15 to 80 elements).
  - Speed controller slider (5ms to 100ms per step).
  - Array randomizer.

Simply open `index.html` in any web browser!

